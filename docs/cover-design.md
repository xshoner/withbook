# 커버 디자인 에디터

편집 화면 상단 **확인할 것** 오른쪽의 **커버 디자인** → 새 창(`/projects/[id]/cover`).

## 펼침면 규격 (`src/lib/cover/spec.ts`)

왼쪽부터 **뒷날개 | 뒷표지 | 책등 | 앞표지 | 앞날개**, 사방 재단 여백 **3mm** (부크크 표지 규격 자동 확인과 같다).

| 항목 | 값 |
|---|---|
| 판형 | A5 148×210 (기본), A4 210×297 |
| 날개 | 좌우 각 100mm (끌 수 있음) |
| 책등 | 미색모조 100g: `{(쪽수 ÷ 2) × 0.11} + 1.6mm`, 0.1mm 반올림. 인쇄소가 준 값이 있으면 [직접]에 입력 |
| 전체 | 3 + 100 + 148 + 책등 + 148 + 100 + 3 × 216mm (책등 15.3mm면 517.3 × 216) |

- 앞·뒤표지 그림은 날개 쪽으로 3mm 더 연장한다(접을 때 밀려도 흰 틈이 없게, 편집기의 연한 붉은 띠).
- 안전 영역: 재단선·접는 선에서 5mm 안쪽(책등은 0.5mm). 벗어나면 [인쇄 점검]에 경고.
- 요소(글·사진)는 패널 기준 좌표로 저장한다. 쪽수를 바꿔 책등 폭이 달라져도 앞표지·날개 요소가 패널을 따라가고, 책등 요소는 가운데 기준으로 옮겨진다.

## 그림 채우기

- **채울 영역**: 펼침면 전체 또는 패널 하나. 패널 그림은 전체 그림 위에 그린다(날개 → 표지 → 책등 순).
- **파일 올리기**: JPG·PNG·WEBP. 영역마다 300 DPI 권장 픽셀을 보여 주고, 채우기/전체 보이기·위치·확대를 조절한다.
- **AI 제작**: `POST /api/projects/[id]/cover/generate {design, region}`
  - 프롬프트 = 기본 지시(편집 가능, [기본값으로]) + 책 정보(제목·부제·저자·주제·핵심 메시지·독자·어조·목차) + 배치(패널별 가로 위치 %) + 글자 지시 + 작가 추가 지시(가장 우선). [고급 · 보낼 프롬프트 보기]에서 그대로 확인한다.
  - "제목·저자명을 그림에 넣기"를 켜면 앞표지 제목과 **책등 세로 제목**을 그림에 넣게 하고, 끄면 글자 없는 배경을 만든다(제목은 [글·사진 → 책 정보로 제목·저자·책등 글 한 번에 넣기]).
  - 요청 크기 `auto`: 영역 비율에 맞춘 최대 크기(긴 변 3840px, 16의 배수, 3:1 이내, 830만 화소 이하). 모델이 400으로 거부하면 1536×1024(세로 영역은 1024×1536)로 한 번 더 요청한다.
  - **300 DPI**: 받은 그림을 영역 비율로 가운데 맞춰 자른 뒤, 영역 크기의 300 DPI 픽셀로 키워(Lanczos) JPEG(품질 92, 4:4:4, density 300)로 저장한다. 펼침면 전체는 약 6,080×2,550px. 모델 출력 자체는 이보다 작으므로 키운 것임을 완료 알림에 원본 크기와 함께 표시한다.
  - 만든 그림은 [만든 그림]에 남아 다시 고를 수 있다(최근 24개). 그림을 만든 뒤 쪽수를 바꾸면 책등 위치가 어긋날 수 있다고 경고한다.

## 글·사진

- 틀: 제목·부제·저자명(앞표지), 책등 제목(세로), 저자 소개(앞날개), 책 소개·추천사·가격/ISBN 자리(뒷표지), 출판사의 다른 책(뒷날개), 패널별 빈 글 상자, 사진(저자 사진 등, 원형 가능).
- 끌어서 옮기기(패널 가운데에 붙음, Alt로 끔), 파란 네모로 크기 조절, 방향키 0.5mm(Shift 5mm), Ctrl+D 복제, Delete 삭제, Ctrl+Z/Ctrl+Shift+Z, Ctrl+S 저장.
- 속성: 글꼴(KoPub 바탕·돋움, Noto Sans/Serif KR, 검은고딕, 도현, 고운바탕, 나눔명조, 나눔손글씨 펜), 크기(pt), 줄 간격, 자간, 굵게·기울임, 정렬, 세로쓰기, 글자 색, 글 상자 배경(색·불투명도), 그림자, 패널·위치(mm).

## 저장·내보내기

- 오른쪽 아래 **저장**: `PUT /api/projects/[id]/cover` → AppSetting `cover:{책 id}` (스키마 변경 없음). 다른 책의 이미지는 거부하고, 이미지 픽셀 크기는 DB 값으로 맞춘다. 저장하지 않고 창을 닫으려 하면 한 번 묻는다.
- **내보내기 (PDF)**: 저장 후 `POST /api/projects/[id]/cover/export` → 서버 Chromium이 `/cover/[id]`(편집기와 같은 `CoverSheet` 컴포넌트)를 열어 재단 여백 포함 크기 한 장으로 인쇄. MediaBox·BleedBox = 전체, TrimBox = 사방 3mm 안쪽. 이미지는 원본 해상도 그대로 들어가고 글꼴은 PDF에 포함된다(Google Fonts 주소는 표지 조판에서만 허용).
- 인쇄 점검 오류(150 DPI 미만, 없는 날개 위의 요소)가 있으면 내보내지 않고, 경고는 확인 후 진행한다.

## AI 연결 (책 설정 → AI 설정 → 표지 디자인)

1. **gpt-image-2.5-sunburst로 설정 (Letsur)** → 주소 `https://gw.letsur.ai`, 인증 `Authorization: Bearer`, 모델 `gpt-image-2.5-sunburst`, 키 이름 `IMAGE_API_KEY`.
2. API 키를 입력하고 **저장하고 연결 점검**. 점검은 그림을 만들지 않고 `GET /v1/models`로 키와 모델 이름만 확인한다(비용 없음).
3. 호출: `POST {주소}/v1/images/generations {model, prompt, size, n: 1, quality: "high"}` → `data[0].b64_json`. 한 번 약 1~3분, 서버 한도 안(약 4분)에서 끝나지 않으면 중단한다. `[ai-call]` 로그와 AiLog(`cover_image`, 예상 비용)를 남긴다.
4. 표지는 기본 연결(글쓰기 모델)을 물려받지 않는다. 개별 연결이 없으면 설정 안내 오류를 낸다.

검증: `npm test`(tests/cover.test.mjs — 책등 공식, 부크크 예시 517.3×216, 영역·해상도·요청 크기·프롬프트·정리·점검), `npm run typecheck`, `npm run build`. 실제 그림 품질·응답 시간·지원 크기는 키를 등록한 뒤 [AI 제작]으로 확인한다.
