## 범위

로컬 작가 1인의 사용 안정성과 단일 서버 웹 배포 준비를 우선했습니다. 다중 사용자 인증·소유권·동시 편집 충돌 해결은 아직 구현하지 않았습니다. DB 스키마와 기존 작가 원고·API 키는 변경하지 않았습니다. 실제 AI 제공자 호출은 검증 과정에서 수행하지 않았습니다. 검증·배포 방법은 [배포 문서](deployment.md)에 정리했습니다.
