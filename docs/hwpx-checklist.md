# HWPX 검증 체크리스트 (한글에서 직접 확인)

앱의 [내보내기 → HWPX]로 받은 파일을 한글(한컴오피스)에서 열어 아래를 확인한다.
부크크 기본 서식(`[한글서식]A5(국판)_부크크서식(기본).hwp`)과 값이 같아야 한다.

| # | 확인 위치 | 기대값 |
|---|---|---|
| 1 | 쪽 → 편집 용지(F7) → 용지 종류 | 사용자 정의 **폭 154mm × 길이 216mm**, 세로 |
| 2 | 편집 용지 → 용지 여백 | 위 18 · 아래 18 · **안쪽 28 · 바깥쪽 23** · 머리말 7 · 꼬리말 13 · 제본 0 |
| 3 | 편집 용지 → 제본 | **맞쪽** |
| 4 | 본문 글자 | KoPub바탕체 Light 10pt |
| 5 | 본문 문단 | 양쪽 정렬, 줄 간격 160%, 첫 줄 들여쓰기 10pt |
| 6 | 장 제목 / 절 제목 | KoPub돋움체 Medium 18pt / 13pt, 장마다 새 쪽에서 시작 |
| 7 | 쪽 번호 | 바깥쪽 아래(홀수 쪽 오른쪽, 짝수 쪽 왼쪽). PDF처럼 본문 첫 장 제목 쪽이 1쪽, 앞붙이·장 제목 쪽·빈 쪽·판권면은 번호 감춤 |
| 8 | 그림 | 글자처럼 취급, 가운데 정렬, 캡션 "그림 N-M" |
| 9 | 판권면 | 문서 마지막 쪽(또는 설정대로 표제지 뒤), **쪽 아래에 붙음**, 부크크 양식 항목 |
| 10 | 차례 | 본문 앞, 장·절 제목 오른쪽 끝에 쪽 번호 — **한글이 장·절 책갈피 쪽을 계산하는 상호 참조**(한글에서 글을 고쳐도 맞는다) |
| 11 | 쪽 수 | 장·절은 새 쪽에서 시작(PDF의 빈 쪽 포함), 장·절 안의 글은 한글이 흘린다 → 쪽 아래가 비지 않고, 전체 쪽 수는 PDF보다 조금 적을 수 있다 |

## 자동 검증 스크립트
`scripts/verify-hwpx.ps1`은 한글 자동화(COM)로 용지·여백·제본·쪽수를 읽어 JSON으로 출력한다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/verify-hwpx.ps1 -Path "내보낸파일.hwpx"
```

- 한글 자동화 보안 모듈(FilePathCheckerModule)이 등록돼 있어야 한다.
- 개발 PC에서는 한글 자동화 창이 응답하지 않아(원본 .hwp 서식도 동일) 자동 검증을 끝내지 못했다. 위 표를 직접 확인한다.
- 생성된 XML은 모두 정상(well-formed)임을 확인했다.

## 참고
- HWPX를 만들 때 PDF와 같은 조판을 먼저 재서(차례 쪽 번호·새 쪽 자리) 그대로 따른다. 문단 속 줄 나눔은 한글이 다시 하므로 한 쪽 안의 줄 위치는 조금 다를 수 있다. 부크크 제출은 PDF를 권장한다.
- 조판을 재지 못하면(시간 초과 등) 차례는 쪽 번호 없이 들어간다.
